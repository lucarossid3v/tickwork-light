# Tickwork Sequencer, web edition

A harmonic step sequencer for the browser: five tracks, one chord line and sixteen patterns, all in key.

**Open it: https://lucarossid3v.github.io/tickwork-light/**

This is the limited web edition. Tickwork for iPad, iPhone and Mac is coming soon.

The source code is not published. This repository holds only the compiled app.

Made by Luca Rossi.
